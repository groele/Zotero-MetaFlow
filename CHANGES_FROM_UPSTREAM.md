The maintained MetaFlow project describes extensions and modifications in areas such as journal abbreviation mapping, scholarly metrics display, metadata verification/enrichment, duplicate detection/merging, arXiv publication reconciliation, attachment file workflows, and Zotero Flow UI/integration. **This list is descriptive, not a verified file-by-file diff or a claim that every feature is independent original code.**
