# Zotero MetaFlow 16.0.3

## 缓存目录与保留策略自定义、界面布局重设计

- **规范缓存文件命名与自定义目录路径**：将缓存目录内的文件规范命名为无版本号后缀的 `api-cache.json`（接口响应缓存）与 `operation-history.json`（操作记录及 `.bak` 备份），并在维护时自动清理历史遗留的 `*-v1.json` 文件。在设置页「数据、缓存与运行反馈 ➔ 缓存目录、有效期与存储维护」中新增目录路径显示框、选择文件夹按钮及恢复默认按钮，默认状态直接展示当前 Zotero 配置目录下的 `zotero-metaflow-cache` 完整路径，支持选择任意可写目录并在切换前自动刷新落盘。
- **6 项缓存有效时长与容量上限自定义**：新增双列网格策略配置区，支持用户按需调整：
  - EasyScholar 缓存有效时长（默认 72 小时，范围 1–720 小时）
  - Semantic Scholar 缓存有效时长（默认 24 小时，范围 1–720 小时）
  - 操作记录保留天数（默认 30 天，范围 1–365 天）
  - 操作记录保留上限（默认 200 次，范围 20–2,000 次）
  - API 缓存容量上限（默认 8 MiB，范围 1–64 MiB）
  - API 缓存索引上限（默认 1,024 条，范围 64–10,000 条）
- **状态与操作卡片化重排**：将原先纵向堆叠的全宽长条按钮重构为结构化的状态卡片与紧凑横向操作工具栏（`.metaref-cache-status-card` + `.metaref-action-row`），实时展示当前生效缓存目录、API 索引进度、操作记录进度与磁盘占用。

兼容声明为 Zotero 10.0–12.*；实际宿主验证范围以发布验证记录为准。
