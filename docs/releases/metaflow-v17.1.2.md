# Zotero MetaFlow 17.1.2

Zotero MetaFlow 发布 **17.1.2** 版本，对化学式上下标改写引擎、跨学科防误伤机制、全大写标题（ALL-CAPS）大小写回溯协同以及手动富文本标题编辑器进行系统性加固升级。

## 核心更新与改进

1. **Unicode 复合角标与同位素左上标精准直译（零语义篡改）**：
   - 重构 Unicode 上下标独立映射通道（并修正上标 `⁷⁸⁹` 码位识别），彻底解决 `PO₄³⁻`、`SO₄²⁻`、`CO₃²⁻`、`Cr₂O₇²⁻` 等酸根离子被拍平混拼为 `PO<sub>43</sub><sup>-</sup>` 的缺陷；
   - 支持同位素上标 `¹³C`、`¹⁵N`、`¹⁸O₂` 及显式 `^13C`、`^18O2` 规范转换为 `<sup>13</sup>C` 等标准标签，同时保留结晶水合物前导系数（`CuSO4 · 5H2O` → `CuSO<sub>4</sub>·5H<sub>2</sub>O`）。
2. **跨学科零误伤防护体系**：
   - 无电荷单元素词元严格限定为真实同核分子白名单，全面拦截 `F1`、`V2`、`S3`、`K12`、`P53`、`P450`、`N95`、`Vitamin B12`、`C4`、`C4.5`、`3D`、`2D` 等非化学编号；
   - 内置过滤流感病毒亚型（`H1N1`、`H5N1`、`H7N9`、`H3N2`）与计算机/商业/工程缩写（`I2C`、`I2S`、`W3C`、`Y2K`、`KN95`、`B2B`、`O2O`、`P2P`、`IC50`、`CC50`、`Ti6Al4V`），100% 零例外通过官方 Sentence Case 全量语料。
3. **重水/氘代试剂与前沿材料催化表达式覆盖**：
   - 新增氘/氚同位素识别（`D2O`、`CDCl3`、`CD3OD`、`ND3`、`D2`、`T2`）；
   - 支持电催化反应缩写（`CO2RR`、`N2RR`、`NO3RR`、`CO2ER`）、二维 MXene 表面端基（`Ti3C2Tx`、`V2CTx`、`Mo2TiC2Tx`）、单原子配位位点（`Fe-N4`、`Co-N4`、`M-N4`）及变量掺杂化学式（`CsPbI3-xBrx`、`La1-xSrxMnO3`、`LiNixCoyMn1-x-yO2`、`NOx`、`SOx`）。
4. **全大写标题（ALL-CAPS）化学式协同与全标题字段覆盖**：
   - 在 `toSentenceCase` 全大写分支中引入化学式大小写回溯还原，智能区分碳氧化物/碳酸盐（`CO2`、`CaCO3`）与钴化合物（`Co3O4`、`LiCoO2`），消除句首 `CO2 → Co2 → Co<sub>2</sub>` 误改；
   - 自动角标改写与手动富文本工具栏同步覆盖 `title`、`shortTitle`、`bookTitle` 与 `proceedingsTitle`。
5. **富文本标题编辑器栈式选区加固**：
   - 选中已有角标内部文本可直接一键剥离还原，杜绝嵌套生成重复标签；支持多位数角标局部拆分、半截跨标签选区吸附对齐及相邻同类标签自动合并。

兼容声明为 Zotero 10.0–12.*，`13/13` 项架构守卫与 `811` 项单元测试全部通过。
