# Zotero MetaFlow 14.0.0

**发布版本：** 14.0.0
**发行类型：** 正式版 / Major release
**兼容范围：** Zotero 10.0–12.*
**运行目标：** Firefox 140 / Gecko 153

## 更新内容

- **移除 CNKI 网络集成**：删除中文题名 CNKI 检索和 CNKI 中文影响因子代理回退。英文文献的 DOI、Crossref、Zotero Translator、Semantic Scholar 与 EasyScholar 主流程不变；选择补充期刊指标时仍可使用本地南农核心表和南农高质量来源。
- **收紧在线结果写入边界**：额外字段中的自由文本 DOI 可用于标识符发现；清理 DOI 周边引用标点，但保留 DOI 自身成对括号；Crossref 与 Semantic Scholar 支持 JSON 对象响应及文本响应。
- **稳健补全作者和 ISSN**：空作者、占位作者、错误作者及本地改动采用一致判定；保留人工修改和原作者角色；ISSN 查询保留 DOI 证据核验及刊名精确回退。
- **拆分元数据应用层**：将条目类型、作者和字段写入从在线服务协调器中拆出，保持原有事务保存边界与字段有效性检查。
- **修正本地规范化边界**：仅对 Zotero 明确标记为双字段的姓名执行对应格式规则；页码连接符支持期刊、会议和章节；期刊名多空格保留；CSL 原始作者拼音字段映射纠正。
- **清理原生菜单与任务通知**：菜单事件去重仅覆盖单次事件分发，关闭顺序先处理子菜单；完成通知隐藏已结束的进度轨道，并在回退生成完成弹窗前收起旧的运行弹窗。

## 安全与数据保留

- 本地“检查并修复”仍保持离线；外部服务仅由用户触发的在线更新链路调用。
- 空白模式不覆盖已有字段；异步期间修改过的字段、作者和标识符会被保留。
- 在线源失败或返回无效数据时不清空本地字段。CNKI 相关历史说明保留为历史证据，不再代表当前服务集。

## 验证

生产构建与 TypeScript 检查通过；单元测试 109 个文件、760 项通过；ESLint 与 AutoCorrect 检查通过。Zotero 10 隔离环境全量原生 E2E 227/227 通过，包括原生菜单连续激活、完成通知复用、元数据补全、事务回滚及生产 XPI 安装。本次未测试 Zotero 11/12。
