**发布日期：** 2026-11-03  
**发布版本：** 13.4.17  
**更新类型：** 核心功能优化与设置规范化（三级层级对齐、TL;DR 回填目标多向支持、路由缺陷修复）

---

## 🚀 核心改进与功能优化

### 1. 设置面板三级层级与边缘距离规范对齐
- 严格遵循 `AGENTS.md` §4.2 设置界面三级层级体系与网格规范：
  - **一级 (Level 1)**：卡片主标题与顶部概述通栏平铺，左右外边距贴合，文字距卡片外框保持 `16px`；
  - **二级 (Level 2)**：主控图标距卡片边缘 `16px`，主选项文字距边缘 `40px`，**牢固确立 40px 黄金纵向对齐基线**；
  - **三级 (Level 3)**：从属说明、从属复选框图标及下拉选项标签起点强制对齐于 `40px` 竖线，文字标签对齐于 `64px`；
  - **嵌套配置卡片**：数据服务设置子卡片左右贴合内容区，统一声明 `padding: 12px 16px;` 标准网格，彻底消除视觉飘移感。

### 2. Semantic Scholar TL;DR 撷论回填多向选择与路由纠偏
- **存储目标自由选择**：设置面板新增「回填存储目标」下拉框（`workflow.tldrTarget`），用户可自主设定核心论点的沉淀位置：
  - **独立子笔记（默认推荐）**：沉淀至专用子笔记，完美适配列表「撷论」列展示与信息面板直接编辑；
  - **Extra 字段**：按用户设定的前缀（`remark:` 或 `TLDR:`）写入 Extra；
  - **双向同时存储**：兼顾子笔记与 Extra 字段；
  - **Abstract 摘要**：将论点保存至子笔记并智能同步回填至空 Abstract。
- **底层路由缺陷修复**：修正了先前逻辑在 `target === 'extra'` 或 `'both'` 时过度调用清洗导致 Extra 论点被剥除的隐患，补全单元测试覆盖。
- **开关联动逻辑增强**：当关闭 TL;DR 提取主功能时，从属的「信息面板常驻显示」与「回填存储目标」自动置灰并降低透明度。

### 3. 本地检查流水线新增查重核对配置
- 新增「检查完成后核对重复候选条目」（`workflow.reviewDuplicatesOnCheck`）选项开关，默认关闭，允许用户按需在本地修复格式完成后无缝唤起重复候选条目核对。

### 4. 国际化与代码库规范化
- 清理 `preferences.ftl` 中历史残留的重复多语言键（`metadata-repair-creators`、`metadata-update-journal-info` 等），确保 Fluent 0 警告；
- 明确版本声明范围为 `10.0` 至 `12.*`，面向未来现代架构演进。
