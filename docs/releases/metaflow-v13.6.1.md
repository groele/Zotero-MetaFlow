# Zotero MetaFlow 13.6.2

**状态：** 本地修复候选，尚未发布或安装至用户主环境。

13.6.2 在 13.6.1 的元数据补全修复基础上，补强审查快照的新鲜度校验：进入原生事务前会比较完整条目快照，覆盖 Extra、标签、集合、关系等非元数据字段，避免用户在等待期间的编辑被旧决定隐式覆盖。

## 修复

- 修正出版商标题在数字上下标前插入换行、缩进时的身份比较，避免同一篇文章被误判为标题冲突而跳过缺失字段补全。
- 使用 DOI `10.1021/acs.nanolett.6c01388` 的真实 Crossref 响应回归：补全缺失刊名 Nano Letters、修复缺名作者；仅补空模式保留已有标题、日期、卷期页码和摘要。
- 独立 ISSN 补全分支核验 Crossref / OpenAlex 返回的 DOI，拒绝缺少或不匹配的 DOI 证据；保留按准确刊名查询的回退。
- 保留作者修复开关、在线更新总开关以及真实标题和 DOI 冲突拦截。未提供的数据不自动编造。

- TypeScript 类型检查、ESLint 和文本检查通过。

- Zotero 11 / 12 与用户主 profile 未在本轮验证；未提交、推送、打标签或发布。
