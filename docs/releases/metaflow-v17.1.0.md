# Zotero MetaFlow 17.1.0

Zotero MetaFlow 正式发布 **17.1.0** 版本，涵盖无密钥/API 双模元数据智能补全、化学式与富文本上下标深度修复、BridgeFlow 风格横向标签设置面板重构及全链路性能优化。

## 核心更新与改进

1. **无密钥 / API 双模自适应元数据补全引擎**：
   - 新增免 API Key 的 `OpenAlexService` 与 Zotero 原生 Translator (`IdentifiersTranslateService` / `ItemTranslateService`) 协同瀑布流，在未配置第三方密钥时即可补齐期刊卷次（Volume）、期号（Issue）、页码（Pages）、精确出版日期（`YYYY` 升级为 `YYYY-MM-DD`）、刊名、ISSN 与作者；
   - 配置 Semantic Scholar / EasyScholar API 密钥后动态提升 API 服务优先级，并自动向下级联补齐缺失书目字段；
   - 统一 OpenAlex DOI 查询缓存键并打通审阅流与 `CompleteMissingISSN` 状态记忆，消除重复外部网络请求。
2. **化学式角标与富文本标题编辑器深度修复**：
   - 默认启用标题化学式规范化，全面支持 Unicode 上下标归一（`H₂O`、`Fe³⁺`）、掺杂化学计量比（`MoS2-x`、`TiO2-δ`）、晶相与连字符前缀（`1T-MoS2`、`2H-WSe2`、`g-C3N4`、`α-Fe2O3`、`TiO2-based`）及配合物括号离子（`[Fe(CN)6]3-`），同时严格保护双原子分子边界防止误伤 `3R`/`1T`/`C4`；
   - 修复富文本标题上下标工具栏与快捷键在复合标签选区及折叠光标下的拆包与状态保持。
3. **BridgeFlow 风格横向标签页设置面板与高可读性视觉升级**：
   - 重构为 6 栏等宽网格横向标签页（`总览工作流` / `格式化规则` / `期刊与缩写` / `查重与合并` / `工具快捷键` / `缓存与维护`），彻底解决窄窗口下横向标签截断问题，窄视口自适应 3×2 网格；
   - 对齐全系浅/深色自适应语义色板与 `40px` 三级黄金基准线，隐藏宿主顶部冗余重复标题，拓宽只读路径框为等宽字体全宽显示，精简冗长说明段落，全面补齐外部配置变更与恢复默认的双向 UI 同步。
4. **全链路架构收敛与运行性能优化**：
   - `onStartup` 并行加载配置与索引并将首次缓存维护延迟至后台空闲期；`onNotify` 微任务合并批量刷新并联动失效指纹缓存；
   - `LintRunner` 预计算批次规则签名并复用 `item.toJSON()` 快照（无改动条目仅序列化 1 次）；虚拟列表 (`ItemTree`) 引入 `WeakMap` $O(1)$ 滚动缓存；大文库查重增加轻量标题 + 年份预筛选跳过 95%+ 无关作者归一化。

兼容声明为 Zotero 10.0–12.*（Gecko 153+ / Firefox 140 现代架构），`812` 项单元测试与 `13/13` 项架构守卫全数通过。
